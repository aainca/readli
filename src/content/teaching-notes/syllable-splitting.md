# Syllable splitting (coaching the split)

## Rule
Long words are read in parts. Find the vowels, count the consonants between them, and split so each part has one vowel sound.

## How to teach
1. Write "rabbit". Have him dot the vowels. Two consonants between them? Split in the middle: rab-bit.
2. Write "robot". One consonant between the vowels? Try splitting before it first: ro-bot. If that sounds wrong (cab-in), split after it.
3. Read each part, then blend. On the next word, only point.

## What to say
"Find the vowels. How many consonants in between? Where does it split? Read each part. Now blend it."

## Common mistakes
He guesses from the first letters. Cover all but the first part.
The blended word sounds wrong. Say "try the other vowel sound" and let him fix it himself.

## Activity
Write napkin, tiger, candle on paper. He dots the vowels, draws the split, and reads them.

## Ready when
He splits a new two-syllable word himself and reads it without help.
